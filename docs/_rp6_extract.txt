2.2 Installation Instructions
2.2.1 Prerequisites Setup
1. Install Java JDK 17
Download: https://adoptium.net/
Verify:
java -version
2. Install Node.js
Download: https://nodejs.org/
Verify:
node --version && npm --version
3. Install Maven
Download: https://maven.apache.org/download.cgi
Verify:
mvn --version
4. Install Docker & Docker Compose (highly recommended)
Windows/macOS: https://www.docker.com/products/docker-desktop/
Linux: Follow official guide
Verify:
docker --version && docker compose version
2.2.2 Backend Setup
Option A: Local Development (Recommended)
1. Clone the repository
git clone https://github.com/<your-org>/SEP490_G43_SJP.git
cd SEP490_G43_SJP/backend
2. Start PostgreSQL via Docker (recommended)
docker run --name srp-postgres \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=smart_recruitment \
  -p 5432:5432 \
  -d postgres:15-alpine
3. Configure environment variables
Create a .env file in the backend/ directory with the following variables:
SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5432/smart_recruitment
SPRING_DATASOURCE_USERNAME=postgres
SPRING_DATASOURCE_PASSWORD=postgres
JWT_SECRET=<your-secret-minimum-32-characters>
FRONTEND_BASE_URL=http://localhost:5173
# Optional: Configure third-party services
# CLOUDINARY_CLOUD_NAME=...
# SHOPAIKEY_API_KEY=...
# GLADIA_API_KEY=...
4. Build and run the application
mvn clean install -DskipTests
mvn spring-boot:run
API available at: http://localhost:8080/api
Swagger UI: http://localhost:8080/api/swagger-ui.html (if configured)
Option B: Using Docker Compose (Best for consistency)
cd SEP490_G43_SJP
docker-compose up -d
2.2.3 Frontend Setup
1. Install packages
cd frontend
npm install
2. Create .env.local
VITE_API_BASE_URL=http://localhost:8080/api
VITE_PORT=5173
3. Start development server
npm run dev
Frontend available at: http://localhost:5173

3. User Manual
3.1 Overview
Smart Recruitment Portal (SRP) is an online job recruitment platform that connects employers with candidates. The system provides intelligent features for job search & matching, AI-powered interview practice, application management, and subscription-based premium services.
Core Features:
Job search with advanced filtering (location, salary, experience, skills, category)
AI-powered mock interview with speech recognition and real-time feedback
Application workflow management (Submit → Review → Interview → Offer → Hire)
Company profile & verification system
Subscription & payment integration (MoMo, VNPay, PayOS, Bank Transfer)
Admin dashboard with user management, job moderation, billing, and statistics
Notification system for real-time updates
CV management with multiple versions
User Roles:
Guest: Browse jobs, view company information
Candidate: Apply for jobs, manage profile/CV, AI interview, subscription
Employer: Post jobs, manage applications, company profile, interview scheduling
Admin: System management, user management, billing, company review, settings
