## Revalidation Summary

- Khong xac nhan P0 Candidate nao trong code hien tai. Cac core flow chinh van ton tai: login/register, profile, CV, search job, detail, save, apply, application tracking, notification, subscription.
- Cac P1 duoc re-check trong code truoc khi dua vao backlog:
  - JWT khong co revocation/version; `JwtAuthenticationFilter` dung claim token de tao user `ACTIVE`.
  - Logout endpoint la no-op; password change/deactivation khong invalidate token da phat hanh.
  - `CandidateProfileRequest` khong co bean validation va profile sections la `List<Object>`.
  - CV upload chi validate ten file/MIME va size; `.gitignore` chua ignore `backend/uploads`.
  - Application submit cho phep fallback CV mac dinh khi request khong gui `cvId`/`cvVersionId`.
  - Checkbox consent trong apply modal khong duoc gui/persist vao backend.
  - Saved jobs/applications/notifications/CVs tra ve list unpaged hoac dung `Pageable.unpaged()`.
  - Modal/dialog khong co focus trap, Escape handling, focus restore.
  - Sidebar notifications tu goi mark-all-read khi click navigation.
- Cac muc AI-only nhu STT, AI scoring, AI transcript draft, AI session URL state, AI fallback evaluation da bi loai khoi backlog nay.

Priority: P0 = critical, P1 = high, P2 = medium, P3 = low/future.

Effort: S/M/L. Risk: Low/Medium/High.
